# 再現性と検証のサマリー

[English](validation-summary.md) | 日本語

過去のラボ実行記録から秘匿情報を除いた要約であり、新たな独立認証ではありません。ここに記載した過去のチェックポイントの生キャプチャー、加入者スナップショット、ホスト識別情報、非公開ワークフローのリンク、操作者の承認記録は配布しません。別途[レビュー済みの1call PCAP例示](../examples/pcap/one-call/README.ja.md)を、完全一致のキャプチャー一覧の例外として用意しています。元の非公開実行記録全体を公開するものではありません。

以下の参照構成のチェックポイントは過去の証拠として保持し、後続の単一VM構成の記録は別に要約します。2026-10-01の文書更新では実機試験を再実行せず、未実施の検査を合格に変更していません。

<a id="クリーンos再現のチェックポイント"></a>

## 6VM参照構成のクリーンOS再現チェックポイント

2026年9月、Linux x86-64ホスト上のネストKVMで独立したUbuntu 24.04環境を作り、固定ソースとコンテナーダイジェストから6ゲストを構築しました。通常UPF疎通、MUPのUL/DL転送、撤回時のフォールバック、オブザーバーリース復旧、UE登録からデータ疎通までのcallが成功し、再適用は変更なしでした。

これは試験したハードウェア上のクリーンOS再現を示しますが、あらゆる物理マシンへの移植性を示しません。2台目の物理ホストでの完全な転送再現、Apple Silicon/ARM64のネイティブ実行は未実証です。前提、資源、一時停止が必要な範囲は[クリーンルーム手順](clean-room-reproduction.ja.md)を参照してください。

<a id="依存関係保守のチェックポイント"></a>

## 6VM参照構成の依存関係保守チェックポイント

2026-09-10の保守実行ではGo 1.26.8、PFCP 1.1.2、MUP-CのGoBGP 4.9.0、両Vinbero PEのパッチ済みGoBGP 4.8.0を使用しました。ロックとチェックサムは `config/versions.lock.yml`、`go.mod`、`go.sum`、Vinberoパッチにあります。

次の検査が成功しています。

- 単体/構文/vet、一部のGo race試験、ShellCheck、ソース依存関係の検査。
- MUP UL/DL転送、ペア撤回/フォールバック、オブザーバーリース復旧。
- 完全なUE callを4回実行し、各回8/8のICMP応答、HTTP疎通、両PEのXDP redirectカウンター増加。
- PEネットワーク再設定からの復旧と、6ゲストAnsible再適用でchanged/failed/unreachableがすべて0。
- ループバックと独立したLinux Tailnet端末からのダッシュボード読み取り。待ち受けはループバックとTailnet IPv4に限定。

これは稼働ラボの更新であり、クリーンOSからの再構築の再実施ではありません。梱包や文書の検査も、これらの実転送試験の再実施ではありません。実行時の変更後は適切な試験を再実行し、新しい配備ごとにリビジョン、カーネル、ロック、コマンド、観測日を記録してください。

単一VMの全試験には1call、baseline/MUP比較、リース、管理されたPE再起動、ネットワーク・近隣復旧を含みます。これらの成功は独立したMUP-C/PEデーモン再起動の網羅、損失の定量評価、校正済み収束時間測定の完了ではありません。HTTP/API検査もダッシュボードの目視受け入れを代替しません。後続のイメージ審査事項と明示的release経路のダッシュボードソケット到達不具合は[イメージ配布](image-distribution.ja.md)に残しており、ソース構築の記録で構築済みイメージの配布を承認しません。

## 受け入れの範囲と今後の記録

別の物理マシンでのクリーン構築は**未検証**です。運用者の判断で今回の受け入れ対象から除外しており、ソース公開の未完了の必須条件ではなく、合格とも記録しません。ARM64/macOSのネイティブ実行、すべての非既定設定、完全オフライン・バイト一致の構築も、これらの記録では実証していません。[研究バックログ](research-backlog.ja.md)は引き続きpendingです。

公開報告には架空のラボ識別情報と集計値だけを残し、生のダッシュボードJSON、PCAP、SSH出力、CI成果物は別途レビューしてください。
