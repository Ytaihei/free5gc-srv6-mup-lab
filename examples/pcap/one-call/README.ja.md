# SRv6 MUP 1callの例示キャプチャー

[English](README.md) | 日本語

隔離ラボの1call試験で取得した、未改変のパケットです。本番通信や生成したプロトコルの模擬データではありません。選択したファイルを配布候補に含めるためのレビューを実施しています。リポジトリ公開や他のキャプチャーの配布を許可するものではありません。本プロジェクトが作成したサンプルと説明には、リポジトリの [LICENSE](../../../LICENSE) を適用します。

## ファイルと観測地点

最初は [00-one-call-all.pcap](00-one-call-all.pcap) を開いてください。234フレーム、32166バイトです。下記6ファイルを時刻順に統合し、パケットのバイト列と時刻を保持しています。インターフェース識別情報はありません。同じ内側パケットが複数区間で見えるため、件数・再送・RTTの評価には個別ファイルを使用してください。

| ファイル | フレーム数 | 見どころ |
|---|---:|---|
| [01-n2-ngap.pcap](01-n2-ngap.pcap) | 20 | Initial Registration、認証・Security交換、PDU Session Resource Setup |
| [02-n4-pfcp.pcap](02-n4-pfcp.pcap) | 12 | 旧セッション削除、新セッション確立・変更と受理応答 |
| [03-bgp-mup.pcap](03-bgp-mup.pcap) | 76 | 旧T1/T2撤回、AFI 1 / SAFI 85の新T1/T2を両PEへ広告 |
| [04-n3-gtpu.pcap](04-n3-gtpu.pcap) | 42 | GTP-Uと内側のUE–DN通信 |
| [05-srv6.pcap](05-srv6.pcap) | 42 | PE間のSRH Type 4と内側IPv4 |
| [06-n6.pcap](06-n6.pcap) | 42 | 通常IPv4、試験ping 8往復とHTTP 200 |

7ファイルの合計は64452バイトです。サイズ、フレーム数、SHA256は[キャプチャー一覧](../../../config/public-pcaps.json)に固定しています。

## 1callを追いかける

既存の `ONE_CALL_ENABLE=1 make test-one-call` は40秒で成功しました。取得範囲は2026-09-11 15:59:16–15:59:56 UTCで、時刻は変更していません。旧UEは `10.60.0.22`、新UEは `10.60.0.23`、DNは `10.210.6.15`、UL TEIDは `90`、DL TEIDは `2`、QFIは `1`、RDは `65000:10` です。新しいT1/T2は論理経路を両PEへ広告しています。

N4 #3–4とBGP #14–16で旧セッション解放、N2 #5でRegistration request、#6–9で認証・Security交換、N4 #5–8とN2 #15/#17でPDU確立、BGP #33/#35–37で広告、SRv6 #9–26で試験ping 8往復、N6 #30/#32でHTTP GET/200を追えます。ダッシュボードの定期pingと直前のセッションの通信も含みます。

```text
ngap || nas-5gs
pfcp.msg_type >= 50 && pfcp.msg_type <= 55
bgp.update.path_attribute.mp_reach_nlri.safi == 85 || bgp.update.path_attribute.mp_unreach_nlri.safi == 85
ipv6.routing.type == 4 && ip.addr == 10.60.0.23
icmp.ident == 0x59fc
http
```

## 残している情報とレビューの限界

意図して残しているのは、ラボIP、ローカル管理の仮想MAC、時刻、テスト加入者 `imsi-208930000000001`（PLMN `208/93`、MSIN `0000000001`）、テスト用セル識別子、認証交換、ラボ由来のNGAPの鍵材料、一時的なセッション識別子、TEID/SID、PFCPのサンプル名 `smf.free5gc.org` / `upf.free5gc.org`、DNN `internet`、HTTPのサーバー版・日付ヘッダーです。実際の携帯加入者や表示される事業者への接続ではなく、ラボfixtureです。HTTP本文は固定のラボページで、私用ブラウジングは含みません。ラボの認証材料を本番認証情報に流用しないでください。

TShark 4.6.4でオフライン解析し、復号表示されたアドレス範囲、仮想MAC、加入者・セッションの文脈、アプリケーション通信を確認しました。既知の非公開識別情報を生バイト・デコーダー出力・IPのバイナリ表現で照合し、一致は0でした。ラボ外のネットワーク接続先は観測されていません。完全な匿名化や、将来の任意のキャプチャーの安全性の証明ではありません。NASの保護されたメッセージは保護されたままで、復号鍵ファイルは含めません。

形式は通常のEthernet PCAPで、インターフェース・名前解決・復号秘密情報のメタデータブロックを持つPCAPNGではありません。元のフレームを保持し、時刻・プロトコル識別子・HTTPメタデータは消去していません。私用の取得スクリプト、ホストのインターフェース対応表、運用ログ、ダッシュボード記録は含めません。

## デコーダーの制約

Wireshark 4.6.4はSource Address Lengthが0のT1経路4件をエラー表示しますが、ラボの基準である [Draft-01](https://datatracker.ietf.org/doc/html/draft-ietf-bess-mup-safi-01#section-3.1.3.1) は0を許容しています。同デコーダーではBGP #14の2個目の撤回NLRIより前に解析が止まる場合があります。T2のTEIDは生バイト `00 00 00 5a` とPFCP/GTP-Uの値 `90` を突き合わせてください。同版では数値フィールドと整形表示が異なります。他の全バージョンでも同じという意味ではありません。

SCTP/BGPは取得前から接続しており、初期ハンドシェイクはありません。N2 #15には再送表示があります。保護されたRegistration Accept/Complete等はすべて平文で読めるわけではなく、元の試験ハーネスではUEログも確認しています。時計はNTP同期されていましたが、ホスト間のサブミリ秒の収束時間を測るための校正は行っていません。

## 検証とサンプル追加

リポジトリのルートで実行します。

```bash
make check-public-source
```

CIはWiresharkなしでレビュー済みバイト列、通常PCAP構造、パケット数を検証します。非公開の最終レビューでは[ソース配布手順](../../../docs/source-distribution.ja.md)に従って外部の私用識別情報リストも指定します。ハッシュはレビュー済みデータを固定するもので、ハッシュの更新だけでは再レビューになりません。

追加・差し替えには、パケット単位のレビュー、日英説明、キャプチャー一覧・公開ソース一覧・完全一致のignore例外への登録、その後のPRレビューとCIが必要です。未登録のPCAP/PCAPNGは引き続きignoreされ、強制追加してソース許可リストに入れるだけでも書き出しを通過できません。
